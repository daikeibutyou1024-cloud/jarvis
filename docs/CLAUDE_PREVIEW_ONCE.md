# Claude実AI・Preview限定1回テスト

この変更は実AIの常時有効化ではない。通常の `/api/chat` と `runAI` の無条件停止は維持する。専用 `/api/business/chat-live-preview` だけが、対象Preview、署名付きログイン、正しいDB識別行、短期のサーバー承認記録、月次台帳、日次回数、未使用の固定operation IDを満たす場合に既存Anthropic処理を1回呼ぶ。

## 今回の実環境確認

- 自動チャージOFFは本人確認済み。現在残高、今月のprovider利用額、他キー/他アプリの消費停止は未確認。
- Previewの実設定 `AI_MONTHLY_BUDGET_USD` は1 USD。依頼文の5 USDより厳しい1 USDを維持し、引き上げない。
- Sonnet 4.6の料金設定は入力3/出力15 USD（各100万tokens）。公式標準料金と照合した。https://platform.claude.com/docs/en/about-claude/pricing
- `AI_OPENING_SPEND_USD_JSON` の確認済み開始利用額は未設定。残高照会用のAnthropic管理連携もなく、推測で埋めない。
- 実APIは送信しない。新しい有効化フラグ・承認情報を環境へ追加しない。実トークン数・実費用・実音声の成否は未確認。

## テスト条件と推定最大費用

モデルは `claude-sonnet-4-6`、最大出力128 tokens。ユーザー発話256文字まで、履歴4件・各256文字まで、最終prompt全体は2048 UTF-8 bytes以下。超過はAPI送信前に拒否し、自動分割・再送しない。画像・tools・cache指定・追加検索・OpenAIへのfallbackは使わない。

入力4096 tokens相当の余裕を含めた推定最大は `(4096*3 + 128*15)/1,000,000 = 0.014208 USD`。専用テストは推定最大の14208 microUSDを既存台帳に事前予約し、実usageで照合する。通常のAI処理の予約計算は変更しない。この推定はprovider請求書の保証ではない。実残高、料金、他経路の停止、月次予算の安全性を確認できなければ送らない。

## 有効化前に必要な事実

本人の管理画面で、残高USD、今月の利用額、他のキー/アプリの停止、自動チャージOFFを確認。元の予算を維持したうえで、月初からの利用を保守的に開始利用額として照合する（既存ローカル台帳との重複加算は過少計上より安全側で停止する）。残高と今月の予算余裕が推定最大費用以上であることを確認し、実送信前にモデル・最大費用・確認結果を報告する。

条件を満たす場合だけ、Previewに限定した `JARVIS_PREVIEW_LIVE_ONCE_ENABLED` と `JARVIS_PREVIEW_LIVE_APPROVAL` を設定する。後者は固定id/モデル/Preview DB ID、確認時刻、有効期限15分以内、残高microUSD、provider月次利用microUSD、他経路停止、自動チャージOFF、maxCalls=1、maxMicroUSD=14208をサーバー側に記録する。開始利用額の月別サーバー設定と一致が必要。クライアントが送る残高・フラグ・operation IDでは解放できない。

## 1回制限とテスト後の停止

既存 `ai_operations` の固定主キー `jarvis-preview-claude-once-v1` を、provider送信前に原子的に確保する。並行タブ、再読込、別端末、別配備からの再送も同じ主キーで拒否する。結果不明・タイムアウト・providerエラーはuncertain予約を保持し、再送しない。日次拒否などで一度確保したIDも削除・再利用しない。台帳テーブルや既存usageをリセットしない。

画面の実AI選択は既定で無効。条件確認GETでサーバーが許可した場合にだけ選択できる。オーブで開始した1発話のみ送信し、回答TTS後は待ち受けへ戻らない。モック選択と排他的にし、実AIの表示・usage・推定費用を区別する。途中で停止しても送信済み要求の課金取消は保証しないが、再送/再開は行わない。

実テスト後はサーバーフラグも無効へ戻す。通信が途絶してその更新が未確認でも、固定IDの消費と期限で追加送信を拒否する。今回は実テストを行わず、フラグ未設定の停止状態を維持する。

## 検証の区別

自動テストはすべて合成キー・使い捨てSQLite・模擬provider/音声。実AI応答の成功を意味しない。Production/main/本番DB/バックアップ/本番キーには変更しない。既存のモック音声会話、文字起こし、保存・承認・天気は維持する。
