# Preview無料CORE（無制限の往復・有料AI不使用）

対象はfeature/ai-business-rebuildのPreviewとlocalhost検証のみ。Production/main/本番DB/バックアップ/既存シークレットを変更しない。

## 会話経路と停止

CORE音声とPreviewの文字入力はcreateFreeDialogueによる定型ルーティングに固定する。旧Claude/一回テスト/モック設定は削除せず画面で保管するが、無料COREでは無効。保存済み・期限付き承認があっても使わない。requestヘルパーも会話関連AI APIへのPOSTを拒否する。無料会話に3往復・日次回数制限は付けない。既存の有料経路の予算・承認制限自体は削除していない。

既存の音声認識・日本語TTS・設定・手動再生・250msのマイク切替待機を再利用する。無料COREは最初の発話待ちにアプリの時間制限を設けない。発話後は約3秒で確定送信。認識サービスが終了/拒否/失敗すれば停止してワンタップ再開を提示し、自動リトライで無理に維持しない。CORE再タップ、終了ボタン、ログアウト、画面非表示で認識/TTS/再待ち受けを止める。

回数上限なしは、端末容量・メモリ・ブラウザ/OSが無限である意味ではない。Safariの自動マイク再開や読み上げが常に許可される保証はない。

## 対応範囲

- BTC価格/分析/ニュース：既存の無料公開レポート。取得失敗・未検証確率は保留のまま。
- BTC追加質問：最新の取得済みレポートの価格・根拠・ニュース・指標・確率保留理由。取得時刻を明示し、前の値を現在価格として扱わない。追加質問だけなら再取得もAI通信もしない。
- 天気：既存Open-Meteo固定地点（富山市）の現在と直近の時間別予報。15分以内の取得結果を使用し、なければ既存更新を1回実施。未取得は未取得とする。雨雲の画像はメニューへ案内する。
- 予定/タスク：この版でGoogleカレンダー連携は既に停止中。予定なしとは言わず未取得と回答。タスクは画面に読み込み済みの業務状況と保存案件のタイトルだけを参照し、未読込のクラウド全件を確認済みとは言わない。追加/変更/削除は音声で実行しない。
- 挨拶、感謝、対応範囲の説明、直前の会話や「N往復前」の記録の参照。

不明な質問は対応できないと説明する。有料AIへのフォールバック、自由な推論、価格/天気/予定の創作はしない。ChatGPTと同等の自由会話AIではない。

## 履歴と文脈

IndexedDB `jarvis-free-dialogue-v1` に新規のturns（追記専用）とcontexts（話題別最新値の索引）だけを作る。旧DB、既存localStorage、下書き、費用台帳、バックアップは変更しない。音声自体は保存しない。会話本文をこの端末内に保存することをCOREに表示する。認証情報らしい入力は既存rejectSecretsで表示/保存前に拒否する。

返答用の直近20往復は作業用で、古い往復は削除せずturnsに残す。BTCの最新レポートは別の索引で保持し、20往復を超えても参照できる。「N往復前」は必要な記録へカーソル移動する。全履歴を毎回AIやローカルモデルへ入力しない。

本人ログイン後の履歴画面で50往復ずつ読み込み、さらに古い履歴や全件JSONを書き出せる。ログアウト時は画面と文脈を隠し、保存データは削除しない。再ログイン後に文脈を復元する。無料COREの会話はクラウドへ自動保存しない。

保存不可/容量不足ではページ内に保持し、警告とJSON書き出しを用意する。保存失敗時の内容は再読み込みで失われる可能性があることを表示し、古い記録の自動削除で空きを作らない。Safariによるサイトデータ消去/プライベート閲覧/異なる端末やPreviewオリジンでの共有は保証しない。継続利用は同じブランチPreview URLを使用する。

## 検証

free-dialogue.test.jsは25往復と60件の保持、作業用文脈との分離、過去記録参照、追加取得なしを検証する。free-core-browser.mjsはPC/スマホで12往復、自動再開、IDB再読み込み復元、有料設定の強制選択を無視すること、音声/認識の排他、CORE終了、API会話リクエスト0を検証する。free-isolation-browser.mjsは文字入力と有料経路遮断、ログアウト時の表示保護を検証する。

iPhone実機のASR/TTS/保存・OS自動再開は未検証。既存の日本語音声優先、速度/ピッチ、数値読み、長文分割、設定保存を維持する。実Claude/OpenAI/その他の有料AIのテストは実行しない。
