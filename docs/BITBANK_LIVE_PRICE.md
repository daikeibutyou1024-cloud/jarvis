# bitbank BTC/JPY現在価格（Preview）

## 配信方式の調査と選択

公式仕様：
- https://github.com/bitbankinc/bitbank-api-docs/blob/master/public-stream.md
- https://github.com/bitbankinc/bitbank-api-docs/blob/master/public-api.md

公式WebSocketは `wss://stream.bitbank.cc` のSocket.IO 4.x / Engine.IO v4。ticker_btc_jpy roomへの参加とheartbeat管理を伴う。単純なJSON WebSocketとして扱わない。この作業環境では実接続の安定性を確認できないため、未検証の独自Socket.IO実装や外部CDNライブラリを導入せず、今回は公式REST Tickerを10秒間隔で取得する。WebSocket配信や毎取引の即時反映ではなく、画面にも「公式API・10秒間隔」と明示する。

## 表示・計算

HOMEのチャート上部に大きなbitbank現在価格、直前の取得価格に対する上昇/下落の矢印と約1.2秒の緑/赤表示、24時間変動率、bitbank配信時刻・サーバー受信時刻・接続状態を表示する。

公開API `GET https://public.bitbank.cc/btc_jpy/ticker` のlast（最終約定価格）を現在価格として表示し、open（24時間前の価格）に対する変動率を `(last / open - 1) * 100` で求める。open=0の場合は変動率未取得。GMOコインのチャートを選んでも現在価格はbitbankのままとし、別取引所であることを表示する。最新価格を確定足の分析や通知候補へ混ぜない。

## 通信・安全性

`GET /api/business/bitbank-ticker-preview` はPreviewホスト/ブランチ・署名セッションを要求する。GET以外・任意の対象指定を拒否し、D1・秘密キー・Claudeは使わない。外部は固定bitbank公開URLへのGETだけ、ヘッダーはacceptのみ。Cloudflare対応のredirect=manualを使い、3xxは追跡せず拒否する。

成功応答はサーバー内で最大5秒キャッシュするが、配信時刻・取得時刻を作り直さない。取得は5秒timeout、本文32KiB。429・HTTP・形式・古い配信時刻などを診断可能なエラーとして返す。APIへのCookie/認証ヘッダー転送はない。日付・last・openを検証し、配信が60秒より古いか5秒以上未来なら最新値として採用しない。架空値・別取引所へのfallbackはない。

ブラウザは1回に1リクエストだけ。通常は成功後10秒で次回を取得する。クライアント側にも8秒timeoutを設ける。失敗時は10/20/40/60秒へ待機を延ばし、5回連続で失敗したら停止して手動再開を案内する。正常通信が戻れば失敗回数をリセットする。認証エラーでは自動再接続しない。価格取得以外の処理を再試行しない。

受信値が30秒以上更新されない、配信時刻が60秒以上前、通信失敗、停止・非表示なら前回値として灰色表示し、最新値であるかのように表示しない。古い順序のレスポンスも採用しない。価格値・接続状態はページ内メモリだけで、既存ストレージや台帳には保存しない。

## 起動・停止

実Previewではログイン完了後、HOMEが表示されている間だけ自動開始する。ボタンで停止・再開できる。停止設定はそのタブ内だけで保持する。

画面非表示、HOME以外への切替、オフラインでは進行中リクエストをabortし、通信・再接続・鮮度タイマーを解除する。復帰時には有効化中の場合だけ再接続する。同じ画面の重複イベントで取得を増やさない。pagehideで停止し、pageshowで状態を確認する。認証待ち・ログアウト・セッション失効では停止する。

バックグラウンドジョブ、Cron、サーバー常駐処理、外部への通知や投稿は追加しない。既存の1年チャート・MA20/50・出来高・分析・FINANCE・音声・天気・保存機能は維持する。Production・main・本番DB・バックアップ・既存環境設定は変更しない。

## 検証と残る制限

単体テストで算出・鮮度・順序・方向・10秒更新・5回上限・timeout・非表示・再開・重複イベント抑制を確認する。PC/スマホ幅のブラウザテストは模擬価格で緑/赤・一時表示・接続状態・停止/復帰を検証する。workerdで実際のTickerルート、署名セッション、manual redirect、公開ヘッダーのみの通信まで確認するが、上流応答はテスト用データであり実価格の検証ではない。

この作業環境からbitbank公開Tickerへの実アクセスはプロキシの制限で利用できず、Web取得ツールも当該URLを取得できなかった。従って実価格・実配信時刻の確認は未完了。Previewでログイン後、現在価格・配信時刻・接続状態が表示されることを確認して初めて実接続成功と扱う。iPhone実機でのバックグラウンド復帰動作も未検証として区別する。
