# Preview BTC初心者向けレポート

COREに「ジャービス、今日の報告をください」「ビットコインの状況を教えて」「今は買い時？」「ビットコインは上がりそう？」と話すと、約3秒の認識イベント無変化後に公開レポートを取得して端末内で読み上げる。入力欄マイクは文字起こし専用のまま。既存の会話認識・TTS・停止・Safari再開処理を再利用する。

ローカル報告の分岐はClaude/モックの送信前。Claudeの停止を解除しない。PreviewでモックOFF・Claude未承認でも市場レポート用に音声入力を開始できる。他の自由会話を有料APIへ勝手に回さず停止する。ProductionはこのレポートAPIを拒否する。

## データと取得

固定の公開GETだけを使う。bitbank BTC/JPY tickerと既存の1年確定日足を使用し、別取引所と混ぜない。Tickerのopenとの比較は24時間比で、暦日前日終値比ではない。直近確定日足終値との比較も別に表示する。高値・安値・出来高が欠ければ未取得と表示。現在価格の鮮度は60秒以内。RSI14、MA20/50、出来高比、過去20本の高安値目安は既存の指標を使う。

FRBの公式金融政策RSS、SECの公式プレスリリースRSS、CoinDesk公開RSSを固定取得する。報道は一次確認未実施、噂と予測は別表示。ニュースは最大7日前まで、時刻不明・未来の公表・出典外URLは除外する。外部XMLエンティティを拒否し、入力サイズと時間を制限する。転送先を自動追跡しない。各ソースの失敗は未取得とし、ニュースが存在しないと断定しない。企業購入/ETF資金等の原資料・金額・因果関係の検証までは実装していない。

見出しを固定ルールで上昇材料候補・下落材料候補・方向未確定に整理する。何が起きたかは原見出し、重要性と需給/金利の説明は定型文。織り込みの程度は未確認であり、価格方向を断定しない。英語の原見出しは画面に残し、日本語音声はカテゴリー・情報の種類と意味を簡潔に説明する。

本人の操作時のみ取得。レポートは60秒キャッシュし、同時取得をまとめる。ニュースは最大3ソース・各6秒・512KiBで、自動再試行しない。D1やキーを使わず、ニュースの定期収集・外部通知・投稿・取引はしない。取得元・配信/取得時刻・検証結果は画面に保持し、本人操作でJSONをダウンロード可能。DBや既存端末保存を変更しない。

## 24時間・7日・30日後の確率

固定の3特徴（RSI、価格と50日平均の比、20日/50日平均の比）による60近傍モデル。最低120件の成熟済み教師標本。各予測時点で結果が既に確定したラベルだけを学習し、未来のラベルを使わない。現在の推定も確定足だけ。

予測対象の期間が重複しない拡大型時系列検証を行う。方向の的中率と95%区間、3分類Brierスコア、過去の方向頻度による基準スコア、各方向の校正誤差を表示する。

数値表示の固定条件は非重複の検証120件以上、校正誤差0.10以下、Brier改善幅の参考95%下限が0より大きいこと。満たさなければ上昇/下落確率を出さず算出保留とする。上昇・下落・横ばいの3分類で、確率が高いだけで購入検討にしない。ニュースは一切学習・確率に使わない。

1年+指標準備期間だけでは特に7日・30日の検証標本が不足する。長期の確率を出すために基準を引き下げない。検証区間の依存性・制度変化・分布変化、モデル比較や区間推定の近似誤差があり、条件通過は将来の信頼性保証ではない。取引手数料・収益性は評価していない。

CPU負荷のある時系列検証はブラウザで実行する。APIは公開データと保留状態を返し、Cloudflare Freeに有料計算サービスを追加しない。

## 判断と未検証事項

購入検討/様子見/警戒は既存の日足分類を基本に、現在価格の50日平均割れ等も確認する。取得・鮮度・指標不足なら様子見（判断保留）。根拠、反対材料、判断が変わる条件を付ける。支持/抵抗は過去高安値の目安で、注文価格を推奨しない。

実環境の公開API/RSS可用性と実相場での精度は未検証。開発環境からの実取得はNETWORK/未取得で終了。架空データへの本番フォールバックなし。模擬データは自動テスト内だけ。iPhone実機の音声・再開は別途確認が必要。Production/main/本番DB/バックアップは変更しない。
