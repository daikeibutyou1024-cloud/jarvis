# Preview：連続会話と日本語音声の調整

既存のVoiceSessionを一元管理のまま利用する。発話前は30秒まで待機し、発話後は約3秒の認識イベント無変化で確定・自動送信する。OSが先に終了した場合や無音・権限・認識エラーでは送信しない。回答生成中と読み上げ中はマイクを止め、読み上げ終了後250msの機器切替待機を挟んで次の発話を待つ。待機タイマーもCORE再タップ・終了・非表示でキャンセルする。自動再開をOSが拒否したら既存の再開ボタンへ戻す。再生エラー時にAPIを再送しない。

実Claudeの既存3往復/セッション、承認回数・期限、プリペイド残高予約、同時実行・日次制限を維持する。無制限の有料会話を有効にした変更ではない。一般の自由回答には承認済みのClaudeが必要で、Previewモックを自由会話の実AIとして表示しない。今回の実APIテストは行わない。

## 音声設定

Web Speech getVoicesでその端末が公開する日本語音声だけを列挙し、保存した音声を優先する。自動選択は名称のEnhanced/Premium等の情報、日本語Siri表記、端末音声・標準指定を参考にするが、名称による優先順は自然さの測定結果ではない。保存した音声がなければ利用できる日本語音声へフォールバックする。iPhoneのSiriや追加ダウンロード音声の全てがブラウザに公開される保証はない。

音声・読み上げ設定から声、速度0.75〜1.25、ピッチ0.8〜1.2を変更できる。標準は速度0.95、ピッチ1。声を試すボタンは端末TTSだけで、APIを使わない。マイク起動中は先に停止し、再タップして試す。再生中に設定を変更した場合は次の再生から適用する。

ON/OFFは既存のjarvis.speech.preference.v1、声/速度/ピッチはjarvis.speech.style.v1だけに保存する。会話本文・鍵・既存の下書きを新しく保存/移行/削除しない。

## 聞き取りやすさ

画面の文章・数値は変更せず、読み上げ用のコピーだけを変換する。円/米ドル/割合/小数は桁を保って漢数字等へ整え、BTCやRSI等は日本語の呼び方にする。段落は句点にし、OSの句読点処理で間を作る。文の切れ目を優先する最大140文字の既存安全分割を維持し、短いフレーズへの過分割や各文ごとの人工的な待ち時間を追加しない。

既存BTC報告の音声は価格・見通し・まとめのつながりを整理する。レポートの確率保留、未取得、事実/報道/噂の区別を変えない。

## BTCの追加質問

同じページで取得した直前レポートに対して「それはなぜ？」「ニュースを詳しく」「確率は？」「RSIとは」「判断が変わる条件は？」をローカル処理する。新しい取得やClaude呼び出しはしない。レポート時点を明示し、今の価格と混同しない。一般の質問や別の話題へ移った後の曖昧な指示を、勝手にBTCへ当てはめない。

ローカル応答もそのタブの短い会話履歴へ追加する。後で承認済みClaudeを使用する場合も既存の直近3往復/入力バイト上限に従う。BTCレポート本体はページの再読み込み/ログアウトで失われるため、追加質問の前に再取得が必要。新しい永続記憶やDB移行はない。

## 限界と検証

PC/スマホ幅のChromiumに模擬マイク・模擬日本語音声・公開報告fixtureを入れ、設定保存、数値の正確な読み、連続報告/追加質問、追加取得ゼロ・有料呼び出しゼロ・読み上げ中の認識禁止・終了キャンセルを検証する。実iPhoneの音声一覧・聴感・マイク自動再開は未確認。声の質や句読点の間、イントネーション、音声の開始許可はOSに依存し、ChatGPTの生成音声の感情・抑揚や同時双方向会話はブラウザ標準TTSでは保証しない。

Production/main/本番DB/既存バックアップ/環境変数/実API承認は変更しない。
